# Пользовательские сценарии

## Установка стабильной версии из npm

**Действие:** оператор выполняет `openclaw plugins install @openclaw-vk/vk-workspace`, включает `vk-workspace` и перезапускает Gateway.

**Результат:** OpenClaw устанавливает актуальную публичную версию из npm; канал доступен для настройки без скачивания архива вручную.

## Обновление после релиза

**Действие:** сопровождающий обновляет версии и CHANGELOG в `main`, после успешных проверок создаёт совпадающий стабильный тег `vX.Y.Z`.

**Результат:** GitHub Actions проверяет пакет и реальный SDK, публикует `@openclaw-vk/vk-workspace@X.Y.Z` в npm через OIDC и создаёт GitHub Release с архивом и контрольной суммой той же версии.

## Отклонение несогласованного релиза

**Действие:** тег не совпадает с `package.json`, либо версии в `package-lock.json` или `openclaw.plugin.json` расходятся, либо в CHANGELOG нет соответствующего раздела.

**Результат:** workflow завершается до npm-публикации и не создаёт GitHub Release.
